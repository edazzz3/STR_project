# STR Viewer — Правила проекта

## О проекте
PWA для просмотра маркшейдерских данных (.str Surpac, текстовые съёмки, PDF-подложки).
Оффлайн-режим, установка на домашний экран телефона, без сборки.

## Жёсткие ограничения (не нарушать)

- **Только Vanilla JS**, ES-модули (`<script type="module">`).
- **Никаких сборщиков** (webpack/vite/rollup), npm, node_modules, транспиляторов.
- **Никаких фреймворков** (React/Vue/Svelte) — только чистый DOM и Canvas.
- **Библиотеки только через CDN**: Three.js 0.160.0 (importmap), pdf.js 3.11.174 (глобальный `pdfjsLib`).
- **Не менять архитектуру** (структуру папок, имена функций, контракты) без явного согласия.
- **Не добавлять зависимости** без обсуждения.
- **Запуск**: `python3 -m http.server 8080` (ES-модули и SW не работают с `file://`).

## Контракты данных (не менять)

Точка (единая для всех слоёв):
    { id, x, y, z, d: [D1, D2, ...] }

Слой STR/TXT:
    { pts: [...], groups: [{ id, idx: [...], text?, center? }], name }

Слой PDF:
    { canvas, width, height, name, affine: { a, b, c, d, e, f } | null }

Аффинное преобразование PDF → мир:
    x = a·u + b·v + e
    y = c·u + d·v + f
    (u — вправо в пикселях PDF, v — вниз)

## Особенности, где легко ошибиться

1. Порядок полей в .str: `номер, Y, X, Z, D1..D4` (Y и X именно в таком порядке!).
2. Ось Y инвертирована: в мире Y вверх, в canvas — вниз. Не сломать преобразования в render2d.js.
3. Стринг закрывается записью с id === 0. Записи с одинаковым id — одна группа-линия.
4. Кодировка .str часто Windows-1251. В readText() есть fallback — не убирать.
5. Точки рисуются поверх линий (два прохода: сначала линии, потом точки).
6. В 3D: X = восток, Y(вверх) = Z съёмки, Z = -север. Не путать с 2D.

## Что уже работает (не переделывать)
- Парсинг .str со стилями (STYLES, DEFAULT_STYLE).
- 2D-canvas: pan, pinch-zoom, колесо, pick точки по тапу.
- Двойной проход отрисовки: линии → точки.
- PDF-подложка с globalAlpha 0.85.
- Привязка PDF по 2–3 парам точек (solveAffine).
- Ленивая загрузка 3D через import().
- Service worker: stale-while-revalidate, кеш str-viewer-v1.
- Safe-area через env(safe-area-inset-*).

## Заглушки (можно улучшать)

## Стиль кода
- Отступ 2 пробела, точка с запятой.
- const/let, без var.
- camelCase для функций/переменных, UPPER_SNAKE для констант.
- Комментарии на русском, коротко.
- Не оставлять закомментированный код.
