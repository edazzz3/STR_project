# STR Viewer — Правила проекта

PWA для просмотра маркшейдерских данных (.str Surpac, текстовые съёмки, PDF-подложки). Vanilla JS, без сборки.

## Жёсткие ограничения

- **Только Vanilla JS**, ES-модули. Без сборщиков, npm, node_modules, транспиляторов.
- **Без фреймворков** (React/Vue/Svelte) — только чистый DOM и Canvas.
- **Библиотеки только через CDN**: Three.js 0.160.0 (importmap), pdf.js 3.11.174 (`window.pdfjsLib`).
- **Не менять архитектуру** (структуру папок, имена функций, контракты) без явного согласия.
- **Запуск**: `python3 -m http.server 8080`.

## Подводные камни (лёгко сломать)

- **`swap` X/Y** — поведение разное: STR — `id,Y,X,Z` (в файле Y первый), TXT — `[имя] X Y Z` (X первый). Не унифицировать.
- **PDF affine** — у слоя `pdf` есть флаг `userAffine`. Если `false` — affine можно пересчитать через `defaultAffine()` при загрузке STR/TXT. Если `true` — трогать нельзя, привязано вручную.
- **`mode3d` + async** — после `await get3d()` обязательно проверять `if (!mode3d) return;`. Иначе гонка.
- **Кеш SW** — при изменении SHELL или структуры кеша поднимать `CACHE = 'str-viewer-vN'`.

## Скважины БВР (172–179)

- **Детект:** точка — устье, если заполнены **оба** поля D9 (азимут) и D10 (наклон). Только по данным, не по ID.
- **Соглашения:** азимут 0°=север, 90°=восток, по часовой; наклон отрицательный = вниз (−90° — вертикально). **Глубина по стволу, не проекция.**
- **Глубина:** D23 (факт) приоритетнее D4 (проект). Оба пусты — ствола нет.
- **Формула и контракт `drill`** — в `computeDrill()` (`strParser.js`), не менять без явного запроса.
- **Стили 172–179** → `kind:'points'`, `labelField:'d3'`. Ствол наследует цвет/толщину стринга.

## Стиль кода

2 пробела, точка с запятой, `const`/`let`, camelCase / UPPER_SNAKE. Комментарии на русском, коротко. Не оставлять закомментированный код.
