# Просмотр STR — PWA-просмотрщик маркшейдерских данных

Оффлайн PWA для просмотра строковых файлов `.str` из Surpac, текстовых съёмок и PDF-подложек
(генпланов, планов горизонтов). Работает в браузере, ставится на домашний экран телефона,
не требует сборки — только статические файлы.

## Что умеет

- Загрузка и отображение `.str` (стринги Surpac) с сохранением стилей (цвет/толщина/тип по номеру стринга).
- Загрузка текстовых съёмок `X Y Z` (`.txt`, `.csv`) — заглушка-парсер, точки выводятся как слой.
- Загрузка PDF через pdf.js — рисуется как подложка под данными.
- Переключение X/Y (в файлах Surpac порядок полей `Y, X, Z`).
- Вписывание в экран, сдвиг одним пальцем, зум двумя пальцами (pinch) и колесом мыши.
- Тап по точке — вывод координат и D-полей в нижнюю строку.
- Привязка (геореференс) PDF по 2 парам точек: тап по месту на PDF → тап по точке данных.
- 3D-режим на Three.js: линии и точки STR/TXT по высоте Z, орбитальная камера.
- PWA: манифест и service worker с оффлайн-кешем.

## Стек

- Vanilla JS (ES-модули, `<script type="module">`), HTML, CSS.
- Без сборщиков и пакетных менеджеров.
- Библиотеки через CDN:
  - **Three.js** `0.160.0` — подключается через `importmap` (`three` и `three/addons/`).
  - **pdf.js** `3.11.174` — глобальный `pdfjsLib`.

## Запуск

ES-модули и service worker не работают с `file://`, поэтому нужен любой локальный HTTP-сервер:

```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080/
```

Для оффлайна один раз откройте приложение с интернетом, чтобы CDN-библиотеки попали в кеш.

## Как это реализовано

### Модель данных слоёв

`app.js` держит состояние в одном объекте:

```js
const layers  = { pdf: null, str: null, txt: null };
const sources = { str: null, txt: null };   // исходный текст для перепарсинга при смене X/Y
```

- Слой `str`/`txt` — результат парсера: `{ pts, groups, name }`.
- Слой `pdf` — `{ canvas, width, height, name, affine }`.
- `sources` хранит исходный текст, чтобы при переключении X/Y не читать файл заново.

Общий контракт точки у всех слоёв данных:

```js
{ id, x, y, z, d: [D1, D2, ...] }
```

### index.html

- Верхняя панель `#top`: кнопки-лейблы со скрытыми `<input type="file">` (PDF / STR / TXT),
  чекбокс «поменять X/Y», тумблер 2D/3D, кнопки «вписать» и «Привязать PDF».
- Два canvas: `#c` (2D) и `#c3` (3D, скрыт по умолчанию).
- Строка статуса `#info` снизу.
- `importmap` объявляет `three` и `three/addons/` для CDN.

### js/app.js — контроллер

- Инициализирует `createRender2d` и передаёт ему геттер слоёв, колбэк статуса и обработчик тапов.
- `readText()` читает файл как UTF-8, при ошибке — как Windows-1251 (кириллица из Surpac).
- `parseLayer(kind)` пересобирает слой из `sources` при загрузке или смене X/Y.
- `redraw(refit)` перерисовывает 2D (и перестраивает 3D, если режим включён).
- 3D-модуль подгружается лениво через `import('./renderers/render3d.js')` только при первом
  включении 3D — чтобы не тянуть Three.js без необходимости.
- Регистрирует service worker после `load`.

### js/parsers/strParser.js

Перенесённая без изменения математики логика разбора `.str`:

- Строка 0 — заголовок. Далее CSV-поля: `номер, Y, X, Z, D1..D4`.
- `id === 0` закрывает текущий стринг. Подряд идущие записи с одним номером образуют группу-линию.
- При `swap` поля X и Y меняются местами.
- Экспортирует `STYLES` (карта стилей по номеру стринга: `kind: 'line'|'points'`, цвет, толщина,
  `labelZ`, `centerD`), `DEFAULT_STYLE` и `centroid()` (площадной центроид контура для подписи в центре).
- Возвращает `{ pts, groups }`, где `groups[i] = { id, idx: [индексы точек], text?, center? }`.

### js/parsers/txtParser.js (заглушка)

- Разбирает строки вида `[имя] X Y Z` (разделители: пробел, табуляция, `;`, `,`).
- Три последних числовых поля — X, Y, Z, всё левее — имя/код точки.
- Возвращает одну группу точек с `id = 'txt'` в том же формате, что `parseStr`.
- `TODO`: реальные форматы тахеометров, заголовки, коды, десятичная запятая.

### js/parsers/pdfOverlay.js

- `loadPdf(file)` — pdf.js рендерит первую страницу в отдельный canvas (scale 2) и возвращает
  `{ canvas, width, height, name, affine: null }`.
- Координаты PDF — пиксели canvas (`u` вправо, `v` вниз). Аффинное преобразование:
  `x = a·u + b·v + e`, `y = c·u + d·v + f`.
- `defaultAffine(pdf, bbox)` — преобразование по умолчанию: PDF растягивается по ширине bbox данных
  и ставится по центру (ось Y инвертирована, т.к. в мире Y вверх, в canvas — вниз).
- `solveAffine(pairs)`:
  - 2 пары точек → подобие (сдвиг + поворот + масштаб) через комплексное деление;
  - 3 пары → полное аффинное по правилу Крамера;
  - вырожденные наборы → `null`.
- `pdfToWorld` / `worldToPdf` — прямое и обратное преобразование.

### js/renderers/render2d.js

- Камера `view = { s, cx, cy, ox, oy }`: масштаб, мировой центр и экранный сдвиг.
- `bounds()` — bbox по всем слоям данных; `fit()` вписывает bbox (или углы PDF, если данных нет).
- `toScreen` / `toWorld` — преобразования мир↔экран (ось Y перевёрнута для экрана).
- `screenToPdf` — экран → координаты PDF через обратное аффинное (нужно для привязки).
- Порядок отрисовки: фон → **PDF снизу** (в своём `setTransform` с аффинным преобразованием и
  `globalAlpha 0.85`) → **STR и TXT сверху** (в два прохода: сначала линии, потом точки, чтобы точки
  были поверх линий).
- `pickPoint(x, y)` — ближайшая точка в радиусе 18 px по всем слоям данных; `pick()` пишет
  координаты и D-поля в `#info`.
- Ввод через Pointer Events: один палец — панорама, два — pinch-zoom, короткий тап
  (< 400 мс и сдвиг < 8 px) — выбор точки. Тап сначала отдаётся `onTap` (привязка PDF), и только
  если не обработан — идёт в `pick()`.
- `setEnabled(v)` скрывает/показывает canvas при переключении в 3D.

### js/renderers/render3d.js

- Сцена Three.js: `WebGLRenderer`, перспективная камера, `AmbientLight` + `DirectionalLight`,
  `OrbitControls` с демпфированием, отдельная группа `content`.
- Система координат: `X = восток`, `Y(вверх) = Z съёмки`, `Z = -север`. Точки центрируются по
  среднему, затем камера выставляется по размеру облака.
- `build(layers)` — заглушка: для каждой группы строится `THREE.Line` или `THREE.Points`
  с цветом из `STYLES`.
- `TODO`: подписи отметок, объёмные трубы для линий, PDF-подложка как текстура на плоскости.
- Рендер-цикл запускается только когда режим активен (`active`).

### css/style.css

- `html, body` фиксированы, `overflow: hidden`, отключены выделение и tap-highlight,
  `overscroll-behavior: none` — чтобы не дёргался интерфейс на телефоне.
- Панели `#top` и `#info` используют `env(safe-area-inset-*)` — учёт «вырезов» и жестовых зон.
- Крупные цели касания (min-height 40 px), тумблер 2D/3D нарисован на CSS (`.track` + `:checked`).
- Canvas занимает весь экран, `touch-action: none` (жесты обрабатываются вручную).

### PWA (manifest.json + sw.js)

- `manifest.json` — `standalone`, свой `start_url`, цвета темы и фона.
- `sw.js`:
  - при `install` кеширует app shell (html, css, все js-модули);
  - при `activate` удаляет старые версии кеша (`str-viewer-v1`) и делает `clients.claim()`;
  - стратегия `stale-while-revalidate`: сначала отдаёт из кеша, параллельно обновляет из сети.
    Так попадают в кеш и CDN-библиотеки при первом онлайн-запуске.

## Управление

| Действие | Жест / элемент |
| --- | --- |
| Сдвиг карты | один палец (drag) |
| Зум | два пальца (pinch) или колесо мыши |
| Данные о точке | короткий тап по точке |
| Вписать в экран | кнопка «вписать» |
| Поменять X/Y | чекбокс «поменять X/Y» |
| 2D ↔ 3D | тумблер в верхней панели |
| Привязать PDF | кнопка «Привязать PDF», затем 2 пары тапов (PDF → точка данных) |

## Ограничения и заметки

- `txtParser.js`, `render3d.js` и режим привязки PDF — базовые/заглушечные, помечены `TODO`.
- Привязка PDF работает только в 2D и требует загруженных PDF и STR/TXT; используется 2 пары точек
  (при необходимости `solveAffine` поддерживает и 3 пары).
- Иконок PWA нет — при установке на домашний экран значок может выглядеть без иконки.
- Для изменения стилей стрингов правьте `STYLES` в `js/parsers/strParser.js`.
