# 📐 Просмотр STR

**Приложение для просмотра маркшейдерских данных** — файлов `.str` из программы Surpac,
текстовых съёмок и PDF-планов карьеров.

Работает прямо в браузере, устанавливается на домашний экран телефона как обычное
приложение и **работает без интернета**. Ничего устанавливать и настраивать не нужно.

---

## 🎯 Что умеет

### 📂 Загрузка данных
- **`.str` файлы из Surpac** — стринги со стилями (цвет, толщина линий по номеру).
- **Текстовые съёмки** (`.txt`, `.csv`) — точки `X Y Z`, с описанием или без.
- **GPS-съёмка с кодами** `vb` / `nb` / `otm` — приложение само построит верхние
  и нижние бровки, отметки.
- **PDF-планы** — генпланы и планы горизонтов как подложка под данными.

Можно загрузить сразу несколько файлов — каждый появится отдельным слоем в панели слева.

### 🗺️ Просмотр в 2D
- Масштабирование и сдвиг: пальцами на телефоне, мышью на компьютере.
- Тап по точке → вся информация внизу: координаты, глубина, азимут, номер скважины.
- Кнопки **«Показать всё»** — вписать весь чертёж в экран.
- Галочка **«Линии»** — соединять точки текстовой съёмки в контур по порядку.

### 🏗️ Просмотр в 3D
- Переключатель **2D ⇄ 3D** в верхней панели.
- Орбитальная камера — вращение, наклон, приближение.
- Виды **«План»** и **«С востока»** для быстрой ориентации.
- Кнопка **«Мишень»** — выбрать точку, вокруг которой крутить чертёж.
- Стволы скважин отображаются как линии.

### 🎯 Привязка PDF к координатам
Если у вас есть план карьера в PDF и координатная сетка на нём — можно привязать
его к реальным координатам двумя способами:

- **Ручной** — тапаете по 2–3 точкам на PDF и по соответствующим точкам съёмки.
- **По углам** — выбираете карьер (ВИ или Б2), тапаете по 3 углам сетки.
  Координаты подставлены автоматически, можно поправить.
  
После привязки PDF встаёт ровно под данные. Внизу показывается точность (RMS).

### 📏 Измерение расстояний
- Кнопка **📏** в верхней панели.
- Тап по первой точке → тап по второй → показывается расстояние.
- **В 2D** — расстояние по плану (без высоты).
- **В 3D** — реальное пространственное расстояние.

### ⛏ Промер БВР (фактические данные по скважинам)
- Кнопка **«БВР»** в верхней панели.
- Выбираете слой `.str` и стринг — приложение показывает таблицу скважин.
- Вводите **фактическую глубину** и **фактический угол** — цифрами, без точек и запятых
  («91» автоматически превратится в «9.1»).
- Enter → переход к следующей скважине.
- Данные сохраняются автоматически (в браузере, до 30 дней).
- **Экспорт в CSV** — для Excel.
- **Экспорт в .str** — готовый файл с фактическими данными, можно открыть в Surpac.

### 🌗 Тёмная тема
- Кнопка **🌙** в правом верхнем углу.
- По умолчанию — светлая.

## 🚀 Как запустить

### На компьютере

1. Скачайте папку с проектом.
2. Откройте терминал в этой папке.
3. Выполните:
   ```
   python3 -m http.server 8000
   ```
4. Откройте в браузере: **http://localhost:8000**

### На телефоне (через GitHub Pages)

Просто откройте ссылку в браузере телефона:

```
https://edazzz3.github.io/STR_project/
```

**Чтобы установить как приложение:**
- **iPhone (Safari):** Поделиться → «На экран Домой».
- **Android (Chrome):** меню (⋮) → «Установить приложение».

После установки — иконка на главном экране, работает как обычное приложение, оффлайн.

## ❓ Частые вопросы

**Нужно ли что-то устанавливать?**  
Нет. Это обычная веб-страница. На телефоне можно добавить на главный экран — будет
выглядеть и работать как приложение.

**Работает ли без интернета?**  
Да, после первого запуска с интернетом. Приложение сохраняет все файлы у себя
и в следующий раз открывается оффлайн.

**Мои данные куда-то отправляются?**  
Нет. Все файлы, которые вы загружаете, обрабатываются только в браузере на вашем
устройстве. На сервер ничего не уходит.

**Где сохраняются данные промера БВР?**  
В браузере вашего устройства. Если почистите историю браузера — данные удалятся.

**Какие браузеры поддерживаются?**  
Chrome, Safari, Edge, Firefox — последние версии. На iPhone — Safari (для установки
на главный экран).
