# str-project-rules
1. Проект работает на чистом Vanilla JS (ES-модули) без сборщиков (Webpack/Vite).
2. Контракты объектов точек ({x, y, z, d: [], drill?}) и слоев в js/state.js менять ЗАПРЕЩЕНО без обновления парсеров и рендеров.
3. При создании или изменении любого JS-файла ОБЯЗАТЕЛЬНО:
   - Добавить файл в массив SHELL в sw.js (если он новый).
   - Поднять версию CACHE в sw.js (например, с v12 на v13).
4. Использовать только CSS-переменные для цветов (поддержка светлой и темной темы).
5. Никаких внешних библиотек, кроме уже подключенных (Three.js, pdf.js).
